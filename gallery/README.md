# Gallery provenance

## World to World Mapping release

[Release video](https://v3b.fal.media/files/b/0aafb407/k_VXzVOBiFnE1RwnpVGxF_world_to_world_mapping-gaussian_splat_to_blender_nodes.mp4)
— **world to world mapping - gaussian splat to blender nodes**.

- Accepted local hybrid experiment: **c26b** (built on c22s; edge diagnostics were not a
  completion blocker). This is the video snapshot, not a claim that the public procedural
  Garden builder reproduces the hybrid without its capture/configuration inputs.
- MP4: 1920×1080, 24 fps, 1,468 frames, approximately 61.17 seconds.
- MP4 SHA-256: `52ba3222124d865002c3d61bb62fb4424b12754aa1ff1fb76fe99b7a76ec06ff`.
- [README thumbnail](world-to-world-mapping.jpg): extracted at 4.17 seconds, resized to
  1280 pixels wide. It is a frame from the rendered release, not a generated illustration.
- Grey/textured reveals and matched reference/clay/hybrid comparison. The comparison
  turn uses 288 shared poses at 1.25-degree increments.

The mapped table and paving are evaluated baked meshes with packed appearance textures.
The original procedural source remains separate; other reconstructed parts retain node
construction. Rough scan boundaries, some soft/stretched appearance, local residual marks,
coverage gaps and baked illumination remain. Captured appearance is not physical albedo or
proof of relightability. The multi-view release is a scoped hybrid result, not exact scene
replication. Its reference imagery retains the source dataset's terms.

The portable mapping tools generalize the study's visibility rejection, robust projection,
actual-material-slot blending, irradiance approximation and localized rejection/fallback.
They require each project's own source, cameras, configuration and masks. Fitted Garden
textures, capture arrays and binary blends are deliberately not distributed in this repo.

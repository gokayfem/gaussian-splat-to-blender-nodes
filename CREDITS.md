  representation; this toolkit reconstructs a different editable representation.
- [Blender](https://www.blender.org/): Geometry Nodes, Shader Nodes and rendering.

Garden is an agent-assisted reconstruction study, not official dataset geometry. Native
r011 gallery media predates later edits in the initial source release. The linked comparison
also shows externally hosted reference imagery; it is not a fidelity certificate.
